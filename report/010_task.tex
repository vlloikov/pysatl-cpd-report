\section{Постановка задачи}

Целью работы является расширение библиотеки PySATL-CPD средствами
применения офлайн-алгоритмов обнаружения разладок к последовательно
поступающим данным и их воспроизводимой оценки.
Для этого планируется интегрировать хотя бы один офлайн-алгоритм,
разработать прототип оконной обработки и дополнить средства оценки
классификационными и специализированными метриками.

Для достижения цели поставлены следующие задачи:
\begin{enumerate}
    \item Интегрировать хотя бы один офлайн-алгоритм CPD
    в текущую версию PySATL-CPD

    \item Разработать прототип механизма скользящих окон
    и проработать обобщение обёрток алгоритмов:
    \begin{enumerate}
        \item сопоставить назначение скрабера из предыдущей версии
        с существующими обёртками \texttt{skipping} и \texttt{batching};
        \item сформулировать контракт обёртки для запуска
        офлайн-алгоритма на окнах и определить, какие элементы интерфейса
        и правила композиции можно обобщить с онлайн-обёртками;
        \item реализовать последовательное накопление наблюдений,
        формирование окон с заданными длиной и шагом
        и запуск выбранного офлайн-алгоритма;
        \item обеспечить преобразование локальных индексов разладок
        в индексы исходного ряда, определить правила объединения
        результатов перекрывающихся окон и сохранения момента обнаружения;
        \item проверить прототип модульными тестами, включая короткие
        последовательности, перекрытие окон, неполное последнее окно
        и сброс состояния.
    \end{enumerate}

    \item Расширить средства количественной оценки
    алгоритмов и их оконных адаптаций:
    \begin{enumerate}
        \item установить применимость существующих классификационных метрик
        и определить правила сопоставления найденных
        и размеченных разладок с допустимым отклонением;
        \item адаптировать существующие и реализовать выбранные
        недостающие метрики;
        \item определить обработку повторных обнаружений,
        рядов без разладок и нескольких вариантов ручной разметки,
        проверить расчёт метрик на примерах с заранее известным результатом.
    \end{enumerate}

    \item Подобрать наборы данных для проверки алгоритмов
    при последовательной обработке наблюдений: описать источники
    и разметку разладок, подготовить загрузку и предобработку данных.
    При необходимости дополнить их синтетическими рядами
    с известными моментами изменений.

    \item Провести воспроизводимые эксперименты с выбранным
    офлайн-алгоритмом, его оконной адаптацией и ограниченным набором
    доступных онлайн-алгоритмов.

    \item Подготовить документацию по интерфейсам офлайн-алгоритма
    и оконной обёртки, пример их совместного использования
    и инструкции воспроизведения экспериментов.
\end{enumerate}
