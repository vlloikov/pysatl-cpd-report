## Название 

Наполнение библиотеки PySATL-CPD 


## Аннотация

Обнаружение разладок во временных рядах позволяет выявлять изменения статистических характеристик наблюдаемого процесса.
При последовательном поступлении данных требуется принимать решения по уже доступным наблюдениям, учитывать задержку обнаружения и контролировать ложные срабатывания.
Библиотека PySATL-CPD предоставляет инструменты для решения таких задач.
Настоящая работа посвящена развитию её возможностей для обработки потоков данных и экспериментальной оценки алгоритмов.

Основным направлением учебной практики является перенос скрабера (scrubber) из предыдущей версии PySATL-CPD в обновлённую архитектуру библиотеки.
Этот компонент формирует скользящие окна данных, которые могут использоваться как входные выборки для совместимых офлайн-алгоритмов обнаружения разладок.
Планируется адаптировать взаимодействие скрабера с поставщиками данных и интерфейсами текущей версии, подготовить модульные тесты и примеры применения.
Корректность работы компонента будет проверяться при последовательной обработке наблюдений.

После переноса предполагается провести сравнительную оценку выбранных алгоритмов при сопоставимых условиях запуска.
При оценке будут учитываться качество обнаружения, ложные срабатывания, задержка обнаружения и вычислительные затраты.
По результатам сравнения будет рассмотрена целесообразность расширения набора алгоритмов.


Для проведения экспериментов предполагается подобрать датасеты, пригодные для последовательной обработки, и описать условия их применения.
При выборе данных будет учитываться наличие разметки разладок либо иной возможности объективно оценить результаты обнаружения.
Подобранные данные должны позволить воспроизводить эксперименты и сопоставлять поведение разных методов.

Ожидаемыми результатами работы за один семестр являются перенесённый и протестированный оконный компонент, результаты оценки выбранных алгоритмов, перечень подходящих датасетов и документация по использованию добавленной функциональности.
При обоснованной необходимости дополнительным результатом станет реализация нового алгоритма.
