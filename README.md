# Наполнение PySATL-CPD

Материалы учебной практики по развитию [PySATL-CPD](https://github.com/PySATL/pysatl-cpd) — библиотеки на Python для обнаружения разладок во временных рядах.


## Направления работы

1. **Перенос скрабера.** Перенести функциональность скрабера из старого репозитория и адаптировать её к архитектуре текущей версии библиотеки для использования офлайн-алгоритмов при последовательном поступлении данных.
2. **Оценка алгоритмов.** Оценить реализованные алгоритмы обнаружения разладок, рассмотреть дополнительные методы и при необходимости реализовать подходящие для включения в библиотеку.
3. **Подбор датасетов.** Найти наборы данных, пригодные для проверки и сравнения алгоритмов обнаружения разладок при обработке потока данных.


## Материалы практики

В этом репозитории по мере выполнения работы будут размещаться:

- название и аннотация работы;
- цель, задачи и ожидаемые результаты в LaTeX-макете отчёта;
- структурированный список источников с краткими обзорами и пояснениями об их применении в работе;
- отчёт и презентации.

Для оформления отчёта будет использован [LaTeX-шаблон математико-механического факультета СПбГУ](https://github.com/spbu-se/matmex-diploma-template). Инструкция по сборке будет добавлена вместе с макетом отчёта.
